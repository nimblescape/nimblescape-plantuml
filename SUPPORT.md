# Support

## Questions and problems

Ask a question or report a problem as an
[issue on GitHub](https://github.com/nimblescape/nimblescape-plantuml/issues).
Search the existing issues first. When an issue describes your problem
already, add your information to that issue.

A report helps most when it contains:

- the version of the extension and the version of VS Code ("Help", "About");
- your operating system;
- the shortest diagram text that shows the problem, in a code block;
- where the problem shows: in the Markdown preview, in the preview of a
  PlantUML file, in a rendered diff, or in the editor;
- what you expected, and what you see instead, for example a screenshot or
  the error message;
- the lines of the log "nimblescape PlantUML" in the Output view (View:
  Toggle Output), when it has lines.

The
[user guide](https://github.com/nimblescape/nimblescape-plantuml/blob/main/docs/guide.md)
describes every feature and what the bundled engine does not support.

## Problems of PlantUML

The extension renders with the PlantUML engine of the npm package
[`@plantuml/core`](https://www.npmjs.com/package/@plantuml/core). When the
same diagram text also renders wrongly in PlantUML itself, for example on the
online server of PlantUML, report it to the
[PlantUML project](https://github.com/plantuml/plantuml/issues).

## Security problems

Do not report a security problem in a public issue. Write an e-mail to
scalarion@nimblescape.com instead.
